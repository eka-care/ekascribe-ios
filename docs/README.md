# EkaScribeSDK Documentation

EkaScribeSDK is a voice-powered medical transcription Swift Package for iOS 15+. It records audio from the device microphone, streams chunks to AWS S3 in real time, and returns structured clinical documents (SOAP notes, transcripts, custom templates) generated by AI on the backend.

## Quick Start

### 1. Add the package (Xcode)

**File → Add Package Dependencies** → enter:
```
https://github.com/eka-care/ekascribe-ios.git
```
Select `EkaScribeSDK` and add it to your target.

### 2. Add microphone permission

```xml
<!-- Info.plist -->
<key>NSMicrophoneUsageDescription</key>
<string>Required for medical transcription recording</string>
```

### 3. Initialize and record

```swift
import EkaScribeSDK

// Implement token storage
class MyTokenStorage: EkaScribeTokenStorage {
    func getAccessToken() -> String? { /* from Keychain */ return nil }
    func getRefreshToken() -> String? { /* from Keychain */ return nil }
    func saveTokens(accessToken: String, refreshToken: String) { /* to Keychain */ }
    func onSessionExpired() { /* redirect to login */ }
}

// Initialize once (e.g. in AppDelegate or app startup)
let config = EkaScribeConfig(
    environment: .production,
    clientInfo: ScribeClientInfo(clientId: "your-client-id"),
    tokenStorage: MyTokenStorage()
)
try EkaScribe.shared.initialize(config: config, delegate: self)

// Start a session
// `mode` is a plain String (e.g. ConsultationMode.id from UserConfigs.consultationModes)
// `modelType` is a String (e.g. ModelType.id from UserConfigs.modelConfigs — ModelType is a struct with id, name, desc)
try await EkaScribe.shared.startSession(
    config: SessionConfig(
        languages: ["en"],
        mode: "consultation",           // ConsultationMode.id
        modelType: "pro"            // ModelType.id
    )
)

// Stop when done — results arrive in didCompleteSession
EkaScribe.shared.stopSession()
```

See [usage-guide.md](usage-guide.md) for the full walkthrough.
